# atfen
**a**symmetrical **t**ext and **f**ile **en**cryption.

---
Atfen is a program made to offline encrypt and decrypt text or files using asymmetrical encryption.

It's made to be not complicated in use, has easily copy-able and shareable public key encoded in Base64.

<img width="506" height="376" alt="image" src="https://github.com/user-attachments/assets/49082e21-17f3-47ce-ba03-276efe37d5cb" />

It uses Tab dividers to not clutter UI between file encrypting and text encrypting.

> [!WARNING]
> Atfen isn't made to be a local file encryptor. Encrypting local files using your own public key is not secure.
> 
> The program rotates the keys at program start, not saving decrypted file/text and closing the program will end up in the loss of the file/text.
>
> Atfen is made to be only a temporary encryptor, encrypting files between uploads.

How to use the program:
1. Exchange your public keys with the person you want to exchange encrypted file/text.
2. Encrypt and send text/file to your peer / wait for encrypted file/text from your peer.
3. After getting text/file, import it to the app and click decrypt.
